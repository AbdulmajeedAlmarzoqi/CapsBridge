# Changelog

## 1.0.0

The first release.

CapsBridge sets up Caps Lock as a screen reader key for Windows virtual machines in VMPal with one button: a helper on the Mac, a key mapping in Windows, and NVDA's setting when NVDA is there. It checks that all of it still holds each time it opens and fixes what doesn't, and it removes everything it added when you ask it to.

It checks for updates once a day and installs them, showing what's new first.

In English and Arabic.
