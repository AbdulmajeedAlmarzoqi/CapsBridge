CapsBridge

Use Caps Lock as your screen reader key in Windows on a Mac.

Download GitHub العربية

Free and open source. Requires an Apple silicon Mac with macOS 26 or later, and VMPal.

Why

In a Windows virtual machine on a Mac, holding Caps Lock does nothing for NVDA, because macOS only tells the virtual machine when Caps Lock turns on or off. CapsBridge fixes that while the Windows window is in front, and leaves Caps Lock alone everywhere else on the Mac.

Installing

  1. Download the zip and open CapsBridge.
  2. Let it move itself to the Applications folder.
  3. Click Set Up, and let it restart Windows when it asks.

To remove it, click Remove CapsBridge… in the app.

Questions

Does it change Caps Lock on the Mac?

No. It only applies while the Windows window is in front.

Does it work with JAWS or Narrator?

It's tested with NVDA. JAWS and Narrator use Caps Lock the same way, but I haven't tried them yet.

How do I update it?

You don't need to. CapsBridge checks for updates and installs them.
